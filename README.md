# Library Management Portal

**Author:** Debangana

An Angular 18 application for the Library Management System.

## Development Server

Run `ng serve` for a development server.

Navigate to `http://localhost:4200/`.

The application automatically reloads when source files change.

## Code Scaffolding

Run:

`ng generate component component-name`

You can also generate directives, pipes, services, classes, guards, interfaces, enums and modules.

## Build

Run:

`ng build`

The build artifacts will be stored in the `dist/` directory.

## Running Unit Tests

Run:

`ng test`

This executes unit tests using Karma.
